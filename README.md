# Strong Gym

موقع وتطبيق ويب تقدّمي لإدارة مشتركي Strong Gym، خطط التمارين المصوّرة، التغذية، الماء، القياسات، والاشتراكات.

## المزايا

- واجهة عربية متجاوبة وقابلة للتثبيت على الهاتف.
- حسابات للمشتركين والإدارة.
- خطط تمارين مصوّرة وتتبع للأداء.
- تسجيل الوجبات والسعرات والبروتين والماء.
- اقتراحات تطوير أسبوعية حسب الأداء والهدف.
- إدارة الاشتراكات والمدفوعات والقياسات.

## التشغيل

الواجهة الجاهزة للنشر موجودة داخل مجلد `dist`، ومخطط قاعدة البيانات داخل `supabase`.

## الحقوق

تم إنشاؤه بواسطة المهندسة أفنان رطروط.
